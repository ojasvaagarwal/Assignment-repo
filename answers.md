1. What is the difference between git clone and git init?
ans. git clone makes a copy of remote repo in local folder whereas git init adds a hidden .git file which it used for tracking changes.

2. What does git status tell you?

3. What is the purpose of git add?
ans. to put files in staging area.

4. What is the difference between git diff and git diff --staged?
ans git diff show changes made on untracked files whereas git diff --staged tell us changes in files under staging area.

5. What is the purpose of git commit?
ans. to commit files before pushing them directly to the source code.

6. What is the difference between git log and git log --oneline?
ans. git log show detailed info including author date and comment of commits but git log --oneline show info in of every commit in single line including just id and comment.
